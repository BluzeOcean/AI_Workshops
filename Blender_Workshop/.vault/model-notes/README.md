# `model-notes/` — what works on this machine

Notes about add-ons, render engines and settings: what each one is good for, and the
settings that worked. Text only — the add-ons themselves live in Blender's own extension
directories.

```
model-notes/<topic>.md
```

Useful things to record here:

- An add-on, its version, and the Blender version it works with.
- Render engine settings that produced a good result (engine, samples, resolution, denoise).
- Export settings that a game engine downstream accepted without complaints.

Record the Blender version in every note. These are versioned facts.
