## Rules for this catalog

1. **Every skill in `.skills/` has a row here, added in the same commit that created the
   file.** A skill that is not in the catalog **does not exist** — no agent will find it.
2. **A row says enough to decide whether to open the file.** If the row is longer than the
   skill behind it, the skill is unnecessary.
3. **The catalog is pruned with the skills, never after them.** A skill whose procedure no
   longer works — a command that changed, a path that moved — is worse than no skill,
   because an agent trusts it. When a prune finds a stale skill, **fix it or mark it**, and
   update this file in the same commit.
