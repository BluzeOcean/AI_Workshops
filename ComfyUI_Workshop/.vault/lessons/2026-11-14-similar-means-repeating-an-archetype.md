# "Similar to previous rounds" means the ARCHETYPE repeated — not the body plan

**Date:** 2026-11-14
**Symptom:** round 04 produced five war mechs. The user kept one (the quadrupedal war hound)
and rejected three as *"too generic / similar to previous rounds"*, plus one for wearing a
cloak. A first reading of that verdict — "bipedal humanoids are generic, ban them" — was
**wrong**, and round 05 then over-corrected into quadrupeds and hexapods the user called
*"useless"*.

**Cause:** the complaint was never about standing on two legs. **The user wants humanoid
mechs.** The rejects repeated an *archetype class* that round 01 had already made:

| Round 04 reject | Round 01 machine it repeated |
|---|---|
| `r04_01` colossal bipedal **siege walker** | `09_titan_bulwark` — heavy siege |
| `r04_04` **shielded** assault walker | `04_bulwark_vanguard` — ablative shield |
| `r04_05` tall spindly machine carrying a **lance** | `02_lance_artillery` / `10_lancet_hover` |

And the one that passed, `r04_02` **quadrupedal war hound**, was the only machine in the set
whose **class** had never appeared before. A quadrupedal hound was new; a second titan was
not.

**Fix:**

1. **Keep the humanoid form.** It is what the user wants and what rounds 01–02 delivered.
2. **Keep a running roster of archetypes already used, and never repeat one.** Write the
   roster into the recipe so the next round can see it.
3. **Vary the design language, not the body plan** — finish, construction vocabulary,
   proportions, palette.
4. **Name the archetype explicitly** in every concept ("a close-combat grappler", "a heavy
   cargo lifter") so the class cannot be misread.
5. Still give every machine a **combat role** and a **weapon**.

### Archetypes already used — do not repeat

- **R01:** scout/skirmisher · long-range artillery · stealth infiltrator · shield vanguard ·
  aerial striker · marksman · blade duelist · support/medic · heavy siege titan · hover
  skirmisher
- **R02:** the same ten, rerun with a decoration layer
- **R04:** siege walker · quadruped war hound · cloaked raider · shielded assault walker ·
  lance walker
- **R05:** quadruped hunter · hexapod artillery · tripod sentinel · heavy ram · segmented
  crawler (all non-humanoid — the round the user rejected)

### Free humanoid classes

close-combat grappler/brawler · heavy cargo lifter · drone-rack commander · incendiary
flamethrower · bolt-thrower crossbow · open-cockpit piloted mech · mine-layer · tool/digger
arm · riot-control unit

### The layout box aspect ratio steers proportion — use it deliberately

The SUBJECT box is a spatial instruction and it measurably sets the machine's build:

- **tall box** (w:h ≈ 0.55–0.75) → an upright humanoid machine. All ten accepted round-01
  humanoids used tall boxes (0.48–0.68 wide × 0.80–0.88 tall).
- **wide box** (w:h ≥ 1.2) → a low horizontal quadruped. Round 04's four tall boxes all
  produced upright bipeds; its only wide box produced the only keeper.

For humanoid mechs, use **tall subject boxes**. For a quadruped, use a wide one.

**Applies when:** a round comes back with "too generic / similar to previous rounds" — check
the archetype roster before changing the subject form.
