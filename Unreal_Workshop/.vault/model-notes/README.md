# `model-notes/` — what works on this machine

Notes about Unreal itself: which version, which settings, what it is good for. Text
only — the app and its add-ons live in their own install directories.

```
model-notes/<topic>.md
```

Useful things to record here:

- A version, an add-on or a plugin, and what it works with.
- Settings that produced a good result (mode, quality, resolution, denoise).
- Export or publish settings that a downstream tool accepted without complaints.

Record the version in every note. These are versioned facts.
