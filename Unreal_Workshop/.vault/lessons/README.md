# `lessons/` — what went wrong, and what to do instead

One file per hard-won lesson. Append-only: never overwrite, add a new one and mark the old
decision `superseded`.

```
lessons/YYYY-MM-DD-short-slug.md
```

```markdown
# <one-line title>

**Status:** active

**Date:** YYYY-MM-DD
**Symptom:** what was observed, literally.
**Cause:** why it happened.
**Fix:** what to do instead — an instruction, not a story.
**Applies when:** the trigger that means this lesson is relevant again.
```

A lesson is worth writing when it cost time, money, or a wrong delivery. "What worked" is
worth writing too — see `../recipes/` for that shape.
